# 0.21.0-beta.1 — Final Python-Line Baseline Release

Status: current
Audience: maintainer, developer, LLM
Lifecycle: permanent
Scope: consolidation release that closes the Python line before the Rust migration experiment
Related: `CHANGELOG.md`, `docs/plans/2026-08-25_rust_migration_plan.md`, `docs/project_status.md`

## Purpose

This release consolidates all post-baseline work into a single stable reference
version of the Python application. The Rust migration
(`docs/plans/2026-08-25_rust_migration_plan.md`) uses this baseline as the comparative-validation
reference: its contracts, database state, outputs, and benchmark numbers are
captured against 0.21.0-beta.1.

After this release, the Python line is feature-frozen. Only regression fixes
required to keep the baseline healthy are accepted.

## Scope of changes since `v0.20.0-beta.1`

Seventeen commits landed between the public beta baseline and this release.
Themes (full detail in `CHANGELOG.md`):

- Beta-validation fixes: bulk image deletion frontier/gamertag handling, stale
  gamertag in the Review write path, `auto_resolved` filter visibility,
  gamertag-change recompute signal, duplicate player laps on reprocessed
  images, and review `updated_at` stamps.
- GUI responsiveness: QThread workers for DB Doctor, image refresh, and Review
  reload; screen-aware sizing; mixed per-column table resize modes; warning
  logs on forced thread termination.
- LM Studio robustness: load-config comparison ignores `physical_batch_size`
  and accepts larger effective `context_length`; cooperative cancellation
  reaches backend construction and backoff waits.
- Operational hardening: exclusive-access `db-reset` with WAL/SHM warnings;
  unique config backups on timestamp ties.
- Structure: `image_service` split into the `forza/application/image` package;
  `RunServiceDatabase` and `ExtractionServiceDatabase` protocols; scoped
  best-lap frontier recomputation (`mark_best_laps_for_groups`) with immutable
  run history and latest-result-per-image frontier selection.
- Prompt accuracy: dirty-lap detection restricted to the upward-triangle
  warning icon adjacent to the lap time.

No schema changes were required by any of these changes.

## Handoff to the Rust migration

Phase 0 of `docs/plans/2026-08-25_rust_migration_plan.md` consumes this baseline:

- `docs/contracts/*.md` are the primary contract source for the Rust port.
- The `*_static.py` tests are the executable-contract catalog to translate.
- A reference execution (screenshots, LM Studio responses, CSV/PDF outputs,
  GUI load timing) must be captured from this exact version before Rust work
  begins, so Python/Rust comparisons have a pinned denominator.
