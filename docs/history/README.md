## Publication boundary

The project was developed privately before the public beta baseline
(`v0.20.0-beta.1`). Pre-beta history records — clean-break removal plans,
quality-audit remediation notes, modular reorganization reports, the
testing-policy rollout archive, and early release records — were not published
with the public repository. References to those files that survive in older
documents are historical context only; treat this directory's post-baseline
records as the available evidence trail.
